# Архитектура сайта

Весь клиентский интерфейс — на немецком. Главная использует Next.js App Router, React, TypeScript и Framer Motion. Остальные 24 страницы генерируются из content/ и scripts/build.mjs. Сборка автоматически обновляет их перед экспортом главной.

## Основные файлы

- src/app/page.tsx — последовательность секций главной.
- src/app/layout.tsx — немецкий язык, метаданные, структурированные данные и подключение согласия на статистику.
- src/app/redesign.css — оформление в исходных белом, синем и тёмно-синем цветах.
- src/components/HeroCarousel.tsx — смена трёх фотографий с паузой, ручным управлением и учётом reduced motion.
- src/components/BeforeAfterSlider.tsx — сравнение фотографий: мышь, касание, клавиатура, захват указателя.
- src/components/ServiceArea.tsx — исходная карта coverage-map.png с анимированными точками и паузой. Это PNG с CSS-анимацией, а не GIF.
- src/components/Services.tsx — услуги, порядок работы, информация о мастере и FAQ.
- src/components/Portfolio.tsx — фотографии с фильтрами.
- src/components/ContactForm.tsx — подготовка сообщения WhatsApp и отправка через существующий Web3Forms.
- src/components/Consent.tsx, src/lib/contact-events.ts, js/site.js, js/attribution.js — общее согласие и статистика главной и внутренних страниц.
- content/services.mjs, content/gallery.json, scripts/build.mjs — отдельные услуги, города и разделы фотографий.
- content/comparisons.mjs, content/coverage.mjs, js/home.js, css/original-theme.css — сохранённые интерактивные элементы и оформление статических страниц.
- /gewerbekunden/ — отдельная B2B-страница для Baumärkte и торговых компаний; использует предоставленные фотографии partner-baumarkt-01.png … partner-baumarkt-10.png.

Не редактируйте public/, out/ и dist/ вручную: они генерируются.

## Запуск и проверки

- npm run dev — разработка главной с обновлением при изменениях, порт 3000. Статические внутренние страницы в этом режиме доступны по полному пути /kuechenmontage/index.html.
- npm run build — обновляет все 25 страниц и экспортирует готовый сайт в dist/.
- npm run preview — весь собранный сайт с правильными адресами разделов, http://127.0.0.1:5500/.
- npm run typecheck — проверка TypeScript.
- npm test — проверка сборки, ссылок, разделения фотографий, сообщений, согласия и ползунков. Сначала выполните build.

По умолчанию сборка приватная: noindex, закрытый robots.txt, аналитика отключена на всех страницах. Для сборки под saarmontage.de задайте SITE_PUBLIC=true. Команды сборки ничего не публикуют. Публикация текущих изменений не выполнена: ранее автоматическая проверка отклонила передачу исходников во внешний Sites; требуется отдельное разрешение пользователя на эту передачу.

## Контакты и статистика

Сохранён номер +49 151 72377683. WhatsApp открывает немецкий текст с услугой, источником saarmontage.de и кодом заявки; посетитель отправляет сообщение самостоятельно. Форма также добавляет введённый город и описание. Ссылки городов ведут на отдельные посадочные страницы.

Google Analytics загружается только на публичном домене после согласия. События whatsapp_click и generate_lead содержат только очищенную категорию услуги, город, страницу и источник. Имена, контакты, тексты сообщений и коды заявки в эти события не передаются. Код в полученном сообщении помогает вручную отличить обращение с сайта; клик по WhatsApp сам по себе не подтверждает отправку сообщения.

Форма показывает успех только после подтверждения Web3Forms. При ошибке данные остаются в форме. Реальные сообщения при проверке не отправлялись.
