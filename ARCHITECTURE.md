# Архитектура обновлённого сайта

Главная перенесена на Next.js App Router + React + TypeScript, Tailwind CSS и Framer Motion. Русские тексты соответствуют заданию. Существующие 23 немецкие страницы услуг, городов и юридической информации сохранены как статические страницы: это поэтапная миграция, а не полная перепись сайта.

```text
src/
  app/
    layout.tsx              # язык, metadata, базовая оболочка
    page.tsx                # последовательность секций
    globals.css             # Tailwind, токены, mobile-first стили
  components/
    Header.tsx              # бренд, sticky, blur при прокрутке
    Hero.tsx                # полный главный экран
    BeforeAfterSlider.tsx   # полный интерактивный ползунок
    Transformation.tsx      # секция сравнения
    Portfolio.tsx           # фильтры и lazy loading
    ServiceArea.tsx         # города → WhatsApp с городом
    Contact.tsx             # контакты и время ответа
    ContactForm.tsx         # WhatsApp + действующий Web3Forms
    Footer.tsx              # юридические ссылки, мобильный CTA
    WhatsAppButton.tsx      # единая кнопка контакта
    Reveal.tsx              # движение с reduced-motion
    Icons.tsx               # интерфейсные SVG-иконки
  lib/
    site.ts                 # номер, контакты, цифры, проекты
scripts/
  prepare-next.mjs          # ресурсы и сохранённые маршруты → public
  export-next.mjs           # Next export → dist для Sites
  build.mjs                # сохранённый генератор прежнего сайта
public/                    # генерируется, не редактировать
out/                       # результат Next.js export
 dist/                     # результат для существующего Sites
```

## Запуск

- `npm install`
- `npm run dev` — http://127.0.0.1:3000
- `npm run build` — готовый статический сайт в `dist/`.
- `npm run typecheck` — TypeScript.
- `npm test` — сохранённые проверки и проверки новой экспортированной главной; сначала выполните build.

По умолчанию сборка приватная: noindex, закрытый robots.txt, аналитика на старых страницах выключена. Для сборки под saarmontage.de в PowerShell: `$env:SITE_PUBLIC='true'; npm run build`. Это только сборка, она ничего не публикует. В новой главной сторонняя аналитика не подключена. Старые страницы сохраняют свою реализацию согласия и статистики в публичном режиме.

## Контакт и контент

WhatsApp использует существующий номер +49 151 72377683. Кнопки открывают подготовленное сообщение, а посетитель отправляет его в WhatsApp. Карточки городов подставляют выбранный город. Форма отправки email использует существующий публичный ключ Web3Forms, сообщает об успехе только после ответа сервиса; при ошибке сохраняет ввод. Реальные сообщения во время разработки не отправляются.

Цифры 4.9/5 и 100+ взяты из задания. Источник рейтинга в проекте отсутствует; перед публичным запуском подтвердите цифры. Рейтинг не привязан к Google и не добавлен в структурированные данные. Время ответа «Обычно в течение рабочего дня» — редактируемый ориентир, его также следует согласовать с мастером.

Использованы собственные фотографии из assets с существующими водяными знаками. Пара karton.jpg / gallery-hero.jpg показывает этапы на разных фотографиях; это иллюстрация процесса, а не подтверждённая фотопара одного заказа. Для точного сравнения одного помещения замените before/after в BeforeAfterSlider.

## Доступность и поведение

- Семантические секции, один H1, навигация, подписи полей, skip link, видимый keyboard focus.
- Native range: мышь, касание, стрелки, Home/End; позиция ограничена 0–100; экранный диктор получает процент изображения до/после.
- Фото лежат в двух одинаковых контейнерах: clip-path раскрывает верхний слой без изменения масштаба.
- Галерея: aria-pressed на фильтрах, объявления количества результатов, loading=lazy, фиксированные пропорции для предотвращения скачков.
- Hero-фото загружается приоритетно. Экспорт использует локальные оригиналы без серверного оптимизатора Next Image.
- Анимации учитывают prefers-reduced-motion. Контент остаётся видимым до выполнения JavaScript.
- Нижняя кнопка на телефоне учитывает safe-area; подвал имеет нижний отступ под неё.

Документация: [Next.js static export](https://nextjs.org/docs/app/guides/static-exports), [Tailwind с Next.js](https://tailwindcss.com/docs/installation/framework-guides/nextjs), [доступность анимаций Motion](https://motion.dev/docs/react-accessibility).
